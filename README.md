# SUMMER-SCHOOL-ONLINE
COLLECTION OF ALL ASSIGNMENTS AT ONE PLACE





## Features

- Unified **calculator** look & feel  
- On-page **digital display** for output  
- Interactive **keypad** inputs instead of prompts/alerts  
- Mobile-responsive design  
- Shared utility file (`js/output.js`) for logging & clearing  



## Installation

1. Clone or download this repository.  
2. Ensure the file structure is preserved:  

   ```
   /project-root
   ├─ index.html
   ├─ variables.html
   ├─ hoisting.html
   ├─ greeting.html
   ├─ loops.html
   ├─ functions.html
   ├─ callbacks.html
   ├─ calculator.html
   ├─ style.css
   └─ js/
      ├─ output.js
      ├─ variables.js
      ├─ hoisting.js
      ├─ greeting.js
      ├─ loops.js
      ├─ functions.js
      ├─ callbacks.js
      └─ calculator.js
   ```

---

## Usage

1. Open **index.html** in your browser.  
2. Click any task button (“Vars”, “Hoist”, “Greet”, etc.).  
3. Interact with the on-screen inputs and keys.  
4. View results in the top “digital display.”  

---

## File Descriptions

- **index.html**  
  Dashboard with links to each exercise, styled as calculator keys.  

- **style.css**  
  Calculator-vibe styling: container, display, keys, colors, typography.  

- **js/output.js**  
  Shared logger:  
  ```js
  log(...args)      // append text to the display  
  clearLog()        // clear the display  
  ```  

- **js/variables.js**  
  Declares one variable of each type, logs name & type.  

- **js/hoisting.js**  
  Demonstrates hoisting for `var` vs `let`, logs errors/value.  

- **js/greeting.js**  
  Takes name & age inputs, logs a customized greeting.  

- **js/loops.js**  
  Runs `for`, `while`, `do…while` loops over user-defined ranges.  

- **js/functions.js**  
  Performs `add`, `square`, and arrow-function greeting.  

- **js/callbacks.js**  
  Applies a callback to double or triple a number.  

- **js/calculator.js**  
  Basic four-function calculator (add, subtract, multiply, divide).
